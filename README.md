# fff — 주식 리서치·매매 기록 저장소

허진호의 미국 주식·옵션 연구실이다. **쌓이는 것**(데이터·코드·검증 결과·매매일지 원본)을 여기에 둔다.
**규칙·알림 지시문·체크리스트**는 claude.ai 프로젝트 "주식" 문서(01 규칙집, 15 알림 지시문, 27 규칙 카드, 47 표준 검증)에 둔다. 매일 22:31 장전 알림이 그 문서를 읽기 때문이다.

## 폴더
| 폴더 | 내용 |
|---|---|
| `data/daily/` | 관심 52종목 + SOXL·SOXX·QQQ 일봉(Twelve Data, 2006-12~2026-11-06, 분할 보정). 열: datetime, open, high, low, close, volume |
| `data/soxx_regime.csv` | SOXX 장 온도: 20일 변동성(v20), 1년 중간값 대비 배수(ratio), 50·200일선 |
| `lab/` | 검증 코드(파이썬). `cd lab && python3 파일.py`로 실행 |
| `results/` | 검증 결과 원문(날짜_이름.txt) |
| `journal/` | 매매일지 원본(토스 체결 기록 정리) — 앞으로 채움 |

## 장 온도 (모든 검증의 기본 틀)
- 🙂 평소 / 🔥 예민(SOXX 20일 변동성 ≥ 1년 중간값 ×1.3) / 🔥🔥 아주 예민(≥ 50%)
- 전날 종가까지의 정보만 쓴다. 2026-05 이후('지금과 비슷한 장')를 따로 본다.
- 표준 검증 규칙: 52종목 × 장 온도 × 2026-05~ × 그 종목 평소 움직임(σ)으로 크기 맞춤 × 옵션 비용 포함 (프로젝트 47 문서 2절)

## 코드
| 파일 | 무엇 |
|---|---|
| `regime.py` | SOXX 장 온도 계산 → `data/soxx_regime.csv` |
| `tests.py` | 공통 함수(블랙-숄즈, 장 온도 라벨, 옵션 거래 모델) |
| `t1.py`·`t1b.py`·`t8.py` | 큰 갭 날(SOXX −3%) 시가 진입·당일 만기 풋 |
| `t2.py` | ±4% 다음 날 추격 |
| `t3.py` | D 반등·금요일 급락→월요일·−5%/+5% 다음 날 |
| `t6.py` | 상승 추세 아무 날 콜 vs 풋 |
| `t52.py` → `s52.py` | 52종목 전체 재검증(갭·추격·D·급락 뒤·양쪽 당일 만기) → 요약표 |
| `t52b.py` | 급락/급등 다음 날 시가 진입 + 빅테크 옵션 탄력성 |

## 한계 (중요)
- 옵션 값은 **블랙-숄즈 모델**이다(IV = 20일 변동성 × 1.2~1.5, 호가 손해 5~15%). 실제 옵션 가격이 아니다.
- 11/9 리서치는 'D 반등 +55%'를 **과장 의심**으로 판정했다. 급락 뒤 실제 IV가 모델보다 높을 수 있다.
- → 실제 옵션 가격 확인은 `results/` 의 real_options 파일(Alpha Vantage 무료 일별 체인)로 일부만 했다.

## 갱신 방법
- 일봉은 Twelve Data MCP로 받는다(무료: 1분 8번). 마지막 날짜 이후만 받아 덧붙인다.
- 새 검증 결과는 `results/YYYY-MM-DD_이름.txt`로 남기고, 결론은 프로젝트 문서(46·47 등)에 요약한다.
